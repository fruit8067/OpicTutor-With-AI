# OPIc 평가 기준 조사 및 프롬프트 반영 기록

조사일: 2026-11-06. 대상은 영어 말하기 NL–AL이다. 인터넷 공식 자료와 사용자가 첨부한 ACTFL 2024 원문을 대조했다. 이 문서는 공식 채점 매뉴얼이나 검증된 예측 모델이 아니다.

## 1. 확인한 자료와 적용 범위

| 자료 | 확인한 내용 | 적용 및 한계 |
| --- | --- | --- |
| [국내 OPIc 공식 시험소개](https://www.opic.co.kr/opics/servlet/controller.opic.site.about.AboutServlet?p_process=move-introduce-opic) | 말하기 평가 영역, NL–AL 설명, IM3 > IM2 > IM1 | 국내 등급 표기의 기준. 확인한 공개 표에는 IM 세분 등급별 상세 판정 경계나 정량 절단점이 없다. 같은 페이지의 읽기·듣기 점수표는 사용하지 않는다. |
| [ACTFL OPIc 공식 소개](https://www.actfl.org/assessments/postsecondary-assessments/oral-proficiency-interview-computer-opic) | 기능·정확성·내용/맥락·텍스트 유형을 종합해 평가; 정확성은 메시지 이해 가능성과 관계됨 | 영역 점수 평균을 공식 등급으로 환산하는 근거가 아니다. 국제 OPIc의 안내 범위는 Superior까지이며 이 앱의 AL 상한과 구분한다. |
| [ACTFL 2024 안내 페이지](https://www.actfl.org/proficiency-guidelines-overview) 및 사용자 첨부 `ACTFL_Proficiency_Guidelines_2024.pdf` | 첨부 PDF pp. 12–15, 17–20의 FACT·지속성·Novice/Intermediate/AL 설명 | 세부 수준 설명은 첨부 원문을 한국어로 재서술했다. pp. 16, 19의 학습 수행 표를 숫자 채점표로 바꾸지 않는다. 이전 공식 PDF 직링크는 조사 시 404였으므로 접근 가능한 공식 안내 페이지를 연결한다. |
| [ACTFL OPIc Familiarization Guide, 2024](https://www.actfl.org/uploads/files/general/OPIc_Familiarization_Guide.pdf), p. 5 | 사전 연습 문항과 시작 자기소개 워밍업을 채점하지 않음 | 국제 안내서에 근거한 앱 설계 선택으로 자기소개를 등급 산정에서 제외한다. 국내 시험의 모든 운영 세부가 동일하다고 일반화하지 않는다. |
| [ACTFL OPIc Validity Evidence, 2023](https://www.actfl.org/uploads/files/general/Documents/assessments/acereports/OPIc_Report_Part_C_Validity_Evidence_2023.pdf), p. 7 | 지속 가능한 수행과 더 어려운 과제에서의 기능 저하를 비교하여 수준을 판단하는 방법론 | 2012 Guidelines를 인용한 2023 연구 보고서다. 관찰 근거를 구조화하는 참고로 사용하고, 현재 국내 채점 알고리즘이나 IM1·2·3 공식 산식으로 주장하지 않는다. |

## 2. 조사에서 얻은 설계 결론

- **일상 과제 수행 → 시간대를 포함한 서술·묘사 → 예상 밖 문제 처리**를 관찰할 수 있어야 한다. 긴 답변 하나만으로 상위 수준을 증명할 수 없다. 수준별 세부 설명의 근거는 첨부 ACTFL 2024 PDF의 Speaking 부분이다.
- **IM1·IM2·IM3 표기는 공식 국내 등급이고, 이 앱이 그 경계를 추정하는 방법은 내부 기준이다.** 표기의 공식성으로 앱의 추정 정확성까지 보장하지 않는다. [국내 공식 표](https://www.opic.co.kr/opics/servlet/controller.opic.site.about.AboutServlet?p_process=move-introduce-opic)
- **정량 지표는 보조 자료다.** 이번에 확인한 공식 자료에서 등급별 최소 단어 수, 필러 개수, 고정 답변 시간, 시제 한 번 오류에 따른 자동 상한을 채점 공식으로 확인하지 못했다. 그런 임계값을 새 공식 기준으로 만들지 않는다. [ACTFL 평가 요소](https://www.actfl.org/assessments/postsecondary-assessments/oral-proficiency-interview-computer-opic)
- **발음과 실제 상호작용은 현재 입력에서 검증할 수 없다.** 이 앱은 외부 평가 모델에 STT와 측정 지표를 전달한다. 말하기 전체 능력과 전사 기반 추정의 차이를 결과에 표시하는 것은 프로젝트의 측정 한계 처리 정책이다.

## 3. 기존 명세와 충돌하거나 보완이 필요한 부분

| 기존 내용 | 개정 결정 |
| --- | --- |
| 자기소개를 포함한 전체 8답변으로 등급 판단 가능 | 8문항 진행·저장은 유지. 1번 자기소개는 `is_scored=false`, 나머지 7문항은 true. 등급의 인용 근거에 자기소개를 사용하지 않는다. 자기소개 연습 피드백은 별도 허용. |
| 단순 문항 유형만 저장 | 설정 시 과제·시간대·맥락 태그와 채점 여부도 스냅샷으로 저장. 모델이 출제되지 않은 능력을 추측하지 못하게 한다. |
| 고정 세트에 미래 시간대 과제가 명시되지 않음 | 검토된 문항의 실제 질문에 미래 계획·예상 결과 등을 요구하는지 확인하고 태그한다. 필요하면 문제 은행을 보강한다. 현재 답변에 미래 표현을 억지로 요구하거나 시험 중 질문을 추가하지 않는다. |
| FACT 1–5 점수에 척도 정의 없음 | 초기 출력은 근거를 포함한 영역별 서술 진단으로 변경. 검증되지 않은 숫자·가중치로 등급을 환산하지 않는다. |
| 프롬프트가 요구사항 안에만 있음 | `docs/prompts/opic_evaluation_system.md`를 로드용 원본으로 추가하고 v1·v2의 수록 본문과 동일하게 유지한다. |

자기소개 제외는 위 국제 안내서를 참고한 이 앱의 정책이며, 8문항·2분 제한도 앱 자체 정책이다. 공식 시험을 그대로 복제했다고 표현하지 않는다. 문제 은행·런타임 구현·API 계약은 이번 문서 수정만으로 자동 변경되지 않는다.

특히 `agents/contracts.yaml` v1과 `agents/14-grader.yaml`의 이전 점수·출력 형식은 구현 연결 전에 동기화해야 한다. 정확한 변경 항목은 v2 F3 출력 계약과 8절을 따른다. 과거 작업 지시를 실행하거나 외부 평가 API를 호출한 것은 아니다.

## 4. 새 프롬프트 구성

`rubric_version=performance-feedback-actfl-speaking-v3`, `prompt_version=opic-evaluation-system-v3`, `im_rubric_version=project-im-v1`.

1. 사용자가 제공한 원래 7단계 표 보존.
2. NL·NM·NH·IL·IM·IH·AL 각각의 수행 특성·발화 구조·판정 주의점 추가.
3. NL/NM부터 IH/AL까지 경계 비교와 기존 내부 IM1·2·3 프로필 유지.
4. 출제된 기능·시간대와 유효 답변을 먼저 확인하고, 전체 수행의 일관성과 기능 저하를 근거로 판정.
5. 자기소개 분리, 기술적 문제와 낮은 수준 구분, 전사만으로 발음 판정 금지.
6. 근거 인용·영역 진단·추가 확인 과제·다음 학습 행동을 구조화.

세부 표·관찰 체크리스트·출력 필드·2개 유형/2개 인용 최소 조건은 교육용 앱을 위한 설계이며 공식 채점 체크리스트가 아니다. 상세 판정 순서가 모델의 내부 사고 과정 공개를 요구하는 것은 아니며, 결과에는 검증 가능한 짧은 판단 근거만 반환한다.

## 5. 구현 전 검증할 사항

- 실제 평가된 **전체 녹음 세트**를 기반으로 NL/NM/NH/IL과 IM 내부, IH/AL 경계의 혼동을 각각 측정한다. 특정 등급 표본이 없으면 그 등급에서 검증되었다고 쓰지 않는다.
- 합성 답변은 형식·규칙 회귀 검증에만 사용한다. 동일 문항의 등급별 합성 답변을 검색해 맞춘 결과를 실제 정확도로 발표하지 않는다.
- 공식 성적이 있는 사용자라도 다른 시점의 앱 답변 세트에 그 성적을 정답으로 복사하지 않는다. 사람 평가자의 독립 평가·이견 조정 자료와 구분한다.
- STT 오류 영향, 초급 답변의 성급한 NL 처리, 자기소개의 등급 근거 혼입, 미출제 기능의 잘못된 감점, 무오류 AL 강요를 점검한다.
- 사용한 문항·답변 ID, 프롬프트·루브릭·모델·코퍼스 버전, 관찰 범위와 제외 이유를 저장한다.

현재 완료 범위는 조사 및 프롬프트/명세 개정이다. 실제 LLM 예측 정확도·문항 커버리지·처리 비용 검증은 별도 구현 및 평가 데이터가 필요하다.
